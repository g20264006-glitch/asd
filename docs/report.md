# 시간과 날씨 데이터 기반 공공자전거 대여량 변동 요인 분석 보고서

## 1. 탐구 질문
시간과 날씨가 주어지면 대여량을 얼마나 잘 추정할 수 있을까?

## 2. 데이터 출처와 범위
- 출처: 수업용으로 생성한 공공자전거 가상 자료
- 주소: 외부 출처 없음
- 이용 조건: 수업에서 활용·수정 가능. 실제 도시의 관측 통계로 인용하지 않기.
- 범위: 가상 도시, 2024-04-01~2024-04-30, 720시간. 오류와 중복을 넣은 정제 연습용 723행.
- 읽은 행 723 → 정제 후 720

## 3. 정제 이유
습도의 물리적 범위(0~100%)를 벗어나는 이상치를 제거하고 날짜 형식을 표준화하여 데이터 분석과 시각화의 신뢰성을 확보하기 위해 정제를 수행했습니다.

## 4. 그래프와 해석

### 요일구분별 대여량 평균 비교
요일별 평균 대여량을 비교해 본 결과, 주말보다 평일에 자전거 대여량이 더 높게 나타나는 패턴을 관찰할 수 있었습니다.

사용 720행 / 빈값 제외 0행. 범주별 기록 수를 함께 확인하세요. 합계와 평균은 다른 질문입니다.

### 기온 × 대여량: 함께 변할까?
기온과 대여량의 산점도를 분석한 결과, 기온이 상승할수록 대체로 자전거 대여량도 함께 증가하는 우상향의 선형 관계가 뚜렷이 관찰되었습니다.

유효 718행 중 718개 점 표시(1,500개 초과 시 고정 무작위 표본). 관계는 원인의 증거가 아닙니다.

### 일별 대여량 평균의 변화
시간의 흐름에 따른 일별 대여량 평균 변화를 선그래프로 시각화하여 특정 날씨 변화나 이벤트에 따라 대여량이 급격히 변동하는 추세를 확인했습니다.

사용 719행 / 날짜·값 누락 제외 1행. 관측값 없는 기간은 선으로 이어 붙이지 않습니다.

## 5. 머신러닝
과제: 회귀 / 정답: 대여량

입력: 시간, 기온, 습도, 풍속, 강수량, 요일구분, 날씨

시간순 분리(서로 다른 시점 기준 앞 약 80% / 뒤 약 20%), 학습 575행, 시험 144행

## 오류에서 배운 점
예측 모델에서 발생한 오차의 원인을 분석한 결과, 급격한 강수나 기상 악화와 같은 돌발 변수가 적절히 반영되지 못해 특정 일자에서 오차가 크게 발생했음을 배웠습니다.


## 결론
공공자전거 대여량은 요일구분과 기온 등의 날씨 요인에 의해 유의미한 영향을 받으며, 특히 평일과 기온이 높은 날에 수요가 크게 증가하는 결론을 얻었습니다.


## 수치 근거
